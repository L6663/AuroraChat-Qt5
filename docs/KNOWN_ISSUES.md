# 已知问题与审查记录

## UI

- Qt 原生 `QMessageBox`、`QInputDialog` 与项目自定义主题不一致，可能出现黑底、低对比度文字、系统图标和英文按钮。
- 辅助窗口需要逐步替换为统一 Aurora 组件。
- 文件进度当前仍以基础进度窗口为主，后续应改为独立的非模态传输任务卡片。

## 截图

旧版会截取整个桌面并直接发送，高分辨率下文件较大，且缺少区域选择。

当前改进方向：

- 截取鼠标所在屏幕；
- 显示全屏区域选择遮罩；
- 裁剪用户选择区域；
- 仅在必要时压缩；
- 上传成功、失败或取消后删除临时文件；
- 后续增加画笔、箭头、矩形、文字和马赛克。

## 文件传输

当前分片协议采用请求/确认顺序，仍需补充：

- 响应超时；
- 分片有界重试；
- SHA-256 完整性校验；
- 断线续传；
- 多任务传输队列；
- 大文件从 SQLite BLOB 迁移至文件系统或对象存储。

客户端已经在发送每个分片前，根据服务端确认的偏移量执行 `seek()`，避免客户端文件指针与服务端接收状态发生漂移。

## 发布状态

当前仓库应定位为持续开发中的工程项目，而不是可直接部署到公网的生产级 IM 服务。公网使用仍需 TLS、令牌会话、限流、强化密码哈希和运行监控。
