# Known Issues and Audit Boundary

## 已在 v1.4.2 中处理并完成局部实机验证

- 所有已知业务 `QDialog::exec()`、`Qt::WindowModal` 和 `Qt::ApplicationModal` 路径已清理。
- 表情改为输入区上方的非模态 PNG 面板，并使用稳定 Token 进行编辑、传输、历史保存和消息气泡渲染。
- 截图功能已按产品决策完整移除，包括工具栏入口、遮罩、预览、编码线程和相关状态。
- 图片预览改为独立非模态窗口。
- 上传和下载改为主窗口内任务卡，不再禁用聊天界面。
- 文件 SHA-256 和图片缩略图生成移入后台线程。
- 异步附件任务冻结发送目标，切换会话不会改变收件人。
- 网络业务请求统一增加超时、同操作替换、迟到响应抑制和断网即时释放。
- 消息历史改为增量插入，并在加载更早消息后保持原滚动位置。
- 客户端文件分片具备超时、重试、取消、重连恢复和 SHA-256 校验。
- 服务端附件正文迁移到文件系统，SQLite 只保存元数据、路径、缩略图和校验值。
- 下载会话按文件偏移读取，不再在内存中保存整份文件。
- 旧整包 Base64 文件协议已停用。

已完成 Qt 5.4 + MinGW 4.9.1 客户端/服务端编译，并使用两个客户端验证私聊文字和 PNG-token 表情。

## 仍需本地验证或后续完善

- 账号注册、重复登录、强制下线完整矩阵；
- 好友申请、接受、拒绝、删除和状态同步；
- 群创建、群消息、成员增删、退出和解散；
- 图片与普通文件的单聊/群聊上传、下载、取消、重试和重连恢复；
- 旧数据库附件首次访问迁移；
- Windows 部署包和缺失 DLL 验证；
- `MainWindow` 仍是较大的协调类，v1.5 将继续拆分；
- 当前客户端一次运行一个上传和一个下载任务，持久化多任务传输中心属于 P1；
- 登录动画、主题编辑器、头像上传、消息引用/撤回和桌宠尚未实现。

## 安全边界

当前项目是 Qt/C++ 求职展示工程，不应直接部署为公网生产 IM 服务。公网使用仍需：

- TLS；
- Token/设备会话机制；
- Argon2、bcrypt 或 scrypt 等密码哈希；
- 登录频率限制；
- 文件病毒与类型检查；
- 审计日志、监控和备份；
- 独立对象存储。
