## 托管职责

### 托管方

- 需求冻结与范围控制
- Issue 拆解与优先级维护
- 源码审查和修复方案
- 协议、数据库和架构一致性检查
- UI 规范与组件统一
- 回归测试清单和版本判定
- README、路线图和求职展示更新

### 本地验证方

- 使用 Qt 5.4 执行 qmake、Debug/Release 编译
- 提供编译日志、运行截图和复现步骤
- 按测试清单执行双客户端、多客户端联调
- 确认 Windows 打包和无开发环境运行结果

## 发布门禁

只有同时满足以下条件，版本才能从 Alpha 升级为 Beta：

- P0 Issue 全部关闭
- 注册、好友、单聊、群聊、截图、文件、断线重连全部回归通过
- 不再混用 Qt 原生业务弹窗
- 文件传输具备超时、重试、校验和取消清理
- README 与真实完成状态一致

## 当前阻塞项

完整托管源码仍需导入 GitHub。导入完成前，仓库中的代码只作为协议、数据库和项目结构基线，不能作为完整可运行版本发布。
