# Aurora Chat 项目概览

## 项目定位

Aurora Chat 是一款基于 **Qt 5.4 + C++** 开发的轻量桌面即时通信系统。项目保留主流聊天应用的核心能力，同时主动排除动态、直播、游戏、商城等与即时通信无关的臃肿模块。

## 核心业务闭环

```text
注册 / 登录
→ 搜索用户
→ 发送好友申请
→ 接受或拒绝
→ 单聊或创建群聊
→ 消息持久化与未读状态
→ 图片、文件、截图传输
→ 断线重连与会话恢复
```

## 主要模块

- 账号、资料与密码管理
- 好友申请与联系人管理
- 单聊、群聊和成员权限
- 消息历史、搜索、草稿、未读与回执
- 图片、文件、截图、上传与下载
- 设置、主题、系统托盘与桌面通知

## 技术栈

- Qt 5.4 / C++11 / Qt Widgets / QSS
- QTcpServer / QTcpSocket
- 固定帧头、长度字段、消息类型、请求编号和 JSON 消息体
- SQLite + Qt SQL
- qmake

## 工程原则

可靠性和交互正确性优先于装饰性功能。登录动画、自定义主题编辑器和桌宠，将在消息可靠性、文件传输和异常恢复稳定后逐步接入。
