# 求职展示简介

## 项目名称

Aurora Chat — Qt 5.4 桌面即时通信系统

## 一句话介绍

基于 Qt 5.4、C++、QTcpSocket/QTcpServer、自定义应用层协议和 SQLite 开发的桌面即时通信系统，覆盖账号、好友、单聊、群聊、消息可靠性、文件分片传输、截图、主题和系统托盘等完整业务链路。

## 技术亮点

- 自定义 TCP 数据帧，处理粘包、拆包和半包；
- 客户端与服务端共享协议枚举和数据结构；
- 消息使用客户端唯一编号实现幂等去重；
- 支持等待网络、发送中、已发送、已送达、已读和失败状态；
- 断线重连后补发待发送消息；
- 历史记录采用游标分页，草稿和本地状态持久化；
- 文件采用 48 KB 分片、服务端确认偏移和进度反馈；
- Qt Widgets + QSS + 自定义无边框组件实现统一桌面 UI；
- SQLite 表结构覆盖用户、好友、群组、消息、附件和消息回执。

## 简历项目描述

> 使用 Qt 5.4 与 C++ 独立开发桌面即时通信系统，基于 QTcpSocket/QTcpServer 设计固定帧头、长度字段、消息类型和请求编号组成的自定义协议，完成注册登录、好友申请、单聊群聊、历史消息、未读状态、消息回执、断线重连和文件分片传输。使用 SQLite 完成业务数据持久化，并通过 Qt Widgets、QSS、自定义弹窗、区域截图和系统托盘提升桌面交互体验。开发过程中采用结构化 Vibe Coding 工作流，对 AI 生成代码进行需求拆解、架构审查、兼容性修复、异常处理和迭代验证。

## 当前开发重点

当前版本仍在持续完善，重点是 UI 组件统一、截图链路、文件传输超时与校验、完整回归测试；之后将加入登录动画、自定义主题和桌面宠物。
