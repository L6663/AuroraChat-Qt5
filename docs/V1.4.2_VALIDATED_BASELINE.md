# v1.4.2 Validated Managed Baseline

## Baseline decision

The managed source version `v1.4.2-alpha-emoji-render-fix` is accepted as the current implementation baseline after local Qt 5.4 compilation and two-client verification of private text and PNG-token emoji messaging.

## Included implementation

- Complete Qt client/server/shared-protocol source in the managed workspace
- SQLite schema and filesystem-backed attachment implementation
- Non-modal interaction core and request tracking
- Reliable 48 KB chunked transfer with timeout, retry, resume and SHA-256 verification
- PNG-token emoji editor/message rendering pipeline
- Light/dark QSS and reusable UI components
- Static, UI, schema, interaction and emoji-pipeline audits

## Product decision

The screenshot feature is removed from the current product scope. Its toolbar action, overlay, preview, encoding worker and related state have been deleted.

## Remaining release gates

This is an Alpha implementation baseline, not a Beta release. Full account, friend, group, image, file, reconnect, old-database and Windows-deployment regression remains required.

## Repository note

Repository documentation and task state are synchronized. The full managed source tree still requires the one-time native Git directory import described in `SOURCE_SYNC_STATUS.md`.
