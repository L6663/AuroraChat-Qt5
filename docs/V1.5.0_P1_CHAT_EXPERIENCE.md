# v1.5.0 — P1 聊天体验阶段

## 目标

在 v1.4.2 交互核心稳定基础上，把聊天页从“正确可用”推进到“符合桌面 IM 使用习惯”。

## 第一批范围

1. 消息右键菜单：复制、回复、转发、撤回；
2. 回复引用条与跳转原消息；
3. 输入框粘贴图片、拖拽图片和文件；
4. 会话置顶、免打扰、标记未读；
5. 聊天区紧凑布局，适配 1366×768 和高 DPI；
6. 继续拆分 `MainWindow` 中的消息和会话协调职责。

## 第二批范围

- 持久化传输中心与多任务队列；
- 群名称、头像、公告和群主转让；
- 用户头像上传。

## 非本阶段范围

- ThemeManager 与主题包；
- 登录动画；
- 桌面宠物；
- 音视频通话。

## 工程门禁

每个功能必须保持 Qt 5.4/C++11 兼容，不允许重新引入：

- `QDialog::exec()`；
- 窗口模态锁定；
- GUI 线程大文件处理；
- 无超时的网络忙状态；
- 消息列表全量清空重建。
